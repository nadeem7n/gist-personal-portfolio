# Nadeem Abbas — Personal Portfolio

A responsive personal portfolio website created for **GIST Full-Stack Web Development Internship — Task 1 (Personal Portfolio Website)**.

## Features

- Dark navy and cyan visual theme
- Responsive layout for desktop, tablet, and mobile
- Sections for introduction, about, skills, projects, education, and contact
- Mobile navigation menu
- Active navigation link based on the visible section
- Contact form demo that prepares an email using the visitor's default email app
- Semantic HTML, keyboard skip link, visible focus states, and reduced-motion support
- No frontend framework or build step required

## Technologies

- HTML5
- CSS3 (Grid, Flexbox, custom properties, responsive media queries)
- Vanilla JavaScript
- Google Fonts (DM Sans and Space Grotesk)

## Run locally

1. Download or clone this repository.
2. Open `index.html` in your browser.

For a local development server, you can use the VS Code **Live Server** extension, or run:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Personalize before publishing

Update the following placeholders in `index.html` and `script.js`:

- `your.email@example.com` with your actual contact email
- LinkedIn and GitHub profile URLs
- Education institution, qualification, and dates
- Project descriptions, statuses, and real project links
- Skill levels to accurately reflect your experience

The contact form is a frontend demo. It does not store messages or send them through a backend; after you configure your email, it opens the visitor's email app.

## Deployment

You can publish this static site with GitHub Pages:

1. Push the project to a GitHub repository.
2. Open repository **Settings → Pages**.
3. Under the build and deployment section, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder, then save.
5. Wait for the deployment URL to appear in the Pages section.
